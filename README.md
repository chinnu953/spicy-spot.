# Spicy Spot – Original Design + Cart

This version keeps the original Spicy Spot design, poster and food images. Changes only requested: remove Admin link from customer page, remove notes, add cart with Add to Cart buttons and bottom cart bar, allow both foods in one order, customer cannot cancel, admin password is CHINNU.

Run in VS Code:
1. Open this folder.
2. Terminal: `npm install`
3. Terminal: `npm start`
4. Open http://localhost:3000
5. Admin: http://localhost:3000/admin (password CHINNU)

Do not use Live Server or open index.html directly.
